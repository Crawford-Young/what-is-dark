# What Is Dark

First-person parkour about facing your own darkness. Phase 1: vertical slice.

Spec: `~/code/docs/games/what-is-dark/specs/2026-07-21-what-is-dark-design.md`

## Commands

- `just run` — play
- `just edit` — open Godot editor
- `just test` — headless GUT unit tests

## Controls (slice)

WASD move, Space jump/vault, Q glance back, mouse look.
